## 📖 เกี่ยวกับระบบ PRIMIS

ระบบ **PRIMIS** ได้รับการพัฒนาขึ้นเพื่อเป็นศูนย์กลางฐานข้อมูลบุคลากรแกนกลาง (Single Source of Truth) ของวิทยาลัยพยาบาลบรมราชชนนี สวรรค์ประชารักษ์ นครสวรรค์ สอดคล้องตามมาตรฐานทะเบียนประวัติ ก.พ. 7 ภาครัฐ และระบบ HROPS กระทรวงสาธารณสุข

### 🌟 โมดูลสำคัญของระบบ:
1. **Public Landing & Dashboard:** แดชบอร์ดสถิติกำลังคนภาพรวมสำหรับบุคคลทั่วไปและผู้บริหาร
2. **ทะเบียนประวัติ ก.พ.7 (33 คอลัมน์):** ประวัติรับราชการหลายช่วง (ลูกจ้างชั่วคราว, พกส., ข้าราชการ) และคำนวณอายุราชการอัตโนมัติ
3. **ระบบการศึกษาต่อ & สัญญาชดใช้ทุน:** บันทึกการศึกษาต่อ 4 รูปแบบ และติดตามภาระสัญญาทุน สบช.
4. **ระบบเครื่องราชอิสริยาภรณ์และเหรียญ ร.จ.พ.:** วิเคราะห์ความพร้อมเสนอขอรอบปี (ครองชั้นตราครบ 5 ปี / เกณฑ์ ร.จ.พ. 25 ปี)
5. **ระบบใบอนุญาตวิชาชีพและบัตรข้าราชการ:** แจ้งเตือนวันหมดอายุอัจฉริยะ (Countdown Tracker)
6. **ระบบประวัติการฝึกอบรม & ผลงานรางวัล:** บันทึกและเสนอขอรับรองเกียรติประวัติ
7. **ระบบประวัติการใช้งานและตรวจสอบความปลอดภัย (Audit Logs):** เก็บบันทึกประวัติกิจกรรมทุกรายการตามมาตรฐาน PDPA
